# monst-orb-manager
## アプリ概要
定期コンテンツだけでどのくらいオーブが集まるか、また、指定した期間内でどのくらいオーブが集まるかを計算するアプリです。

主に、コラボなどの期間限定イベントに向けて、どのくらいオーブを集められるか知りたい人、特に無課金や微課金でプレイしている人を対象にしています。

このアプリを使うことで、獲得できるオーブの合計を簡単に計算でき、自分でオーブを管理しやすくなります。

## 作った理由
定期コンテンツの開催期間を毎回確認したり、イベントの期間内でどれくらいオーブが集まるかを自分で計算したりするのが面倒だったため、このアプリを作りました。

## 主な機能
- 定期コンテンツの開催中・開催前表示
- 終了まで／開催までのリアルタイムカウント
- オーブ回収済みのチェック
- ログインオーブの自動計算
- 轟絶ボーナスの7日周期での計算
- 指定期間の獲得オーブ予測
- 期間内に開催されるコンテンツの自動表示
- 開催回ごとの個別選択
- 獲得オーブ合計の自動計算

## 工夫した点
リアルタイムの日時と連携し、各定期コンテンツが現在開催中なのか、開催前なのかを分かりやすく表示できるようにしました。

また、各コンテンツのアイコンを表示することで、一目で分かりやすいようにしました。

禁忌の獄や破界の星墓など、開催期間が月をまたぐコンテンツについても正しく処理できるようにしました。

さらに、同じ定期コンテンツが指定した期間内に複数回開催される場合でも、開催回ごとに別々に表示し、個別に選択できるようにしました。
